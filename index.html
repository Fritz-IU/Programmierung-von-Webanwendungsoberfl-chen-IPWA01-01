Wilkommen bei KleiSper.
Anlaufstelle für deine Altkleider.

Unsere Mission:

Wir sammeln Kleiderspenden und bringen diese in verschiedene Krisengebiete. Dabei kann das Krisengebiet, in das die gespendeten Kleider gebracht werden sollen, bei der Spende angegeben werden. Es gibt eine von uns evaluierte Auswahl an aktuellen Krisengebieten, in denen Kleiderspenden benötigt werden.
Die Kleiderspenden können entweder an der Sammelstelle direkt abgegeben oder von einem unserer Sammelfahrzeuge eingesammelt werden. Eine Abholung ist nur im Postleitzahlbereich 38 möglich. In beiden Fällen muss das untenstehende Formular ausgefüllt werden.

Kleiderspende registrieren:

Sollen die Kleider abgeholt oder vor Ort abgegeben werden?

Bitte wähle ein Option aus.
Bitte wähle ein Krisengebiet aus.
Bitte gib deinen Vornamen an.
Bitte gib deinen Nachnamen an.
Bitte gib eine E-Mail-Adresse an.

Angaben für die Abholung:

Bitte gib eine Straße an.
Bitte gib eine Hausnummer an.
Bitte gib eine Postleitzahl von 38000 bis 38999 an.
Bitte gib eine Stadt an.

Wunschtermin für die Abholung:

Bitte wähle ein Datum aus.
Bitte wähle einen Zeitslot aus.

Angaben zu den Kleidern:

Art der Kleidung Größe Menge Entfernen
Bitte gebe mindestens ein Kleidungsstück zur Spende an.
